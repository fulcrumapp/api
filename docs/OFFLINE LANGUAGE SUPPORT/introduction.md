## Offline Language Support in Fulcrum

Fulcrum Rosetta Stone enables multilingual field data collection by translating existing Fulcrum applications into multiple languages, even without an internet connection.

Using on-device translation, field teams can translate form labels, choice lists, and supported text fields while continuing to work offline.

Rosetta Stone supports **English, Spanish, French, Polish, and Slovak** and is compatible with **Android, iOS, and Fulcrum's desktop/web application**.

### Key Capabilities

- **Offline translation:** Translate forms directly on your device without an active internet connection.
- **Multilingual forms:** Support English, Spanish, French, Polish, and Slovak.
- **Existing applications:** Add translation capabilities to your current Fulcrum apps without rebuilding them.
- **Choice list compatibility:** Translate displayed choice labels while preserving stored values used by calculations and Data Events.
- **Cross-platform support:** Available for Android, iOS, and desktop/web.
- **Simple installation:** Install language packages using the Fulcrum Rosetta Stone installer.

### Getting Started

To enable offline language support, follow the [Fulcrum Rosetta Stone Quick Start & User Guide](fulcrum-rosetta-stone/quick-start.md).

For additional information, see:

- [Technical Architecture](fulcrum-rosetta-stone/technical-architecture.md)
- [Release Notes & Compatibility](fulcrum-rosetta-stone/release-notes.md)

**Note:** An internet connection is required for initial installation and synchronization. Once the language packages are synchronized, translation runs locally without an internet connection.
